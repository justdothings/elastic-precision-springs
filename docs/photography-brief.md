# Product Photography Brief

The current website code includes placeholder visual assets and/or externally sourced reference images for development. Before public launch, replace them with company-owned photography or properly licensed stock.

## Required Shots

1. Compression springs — multiple sizes, stainless and spring steel variants.
2. Extension springs — hooks visible, side-lit macro shot.
3. Torsion springs — legs visible, photographed with angle/measurement cues.
4. Wire forms — several custom bends on a technical drawing background.
5. Precision turned parts — small batch detail shot, clean industrial surface.
6. Wire conveyor belts — flat lay and angled shot, preferably with food/cooking/cooling context.
7. Workshop/process — coiling, forming, inspection, calipers, material wire rolls.
8. RFQ context — drawing/photo/sample near caliper and email/contact visual.

## Visual Style

- Background: dark graphite, blackened steel, brushed metal, or matte deep gray.
- Lighting: side lighting + rim highlights to reveal coil geometry.
- Props: calipers, micrometer, technical drawings, measurement ticks, material labels.
- Avoid: cluttered benches, dirty surfaces, blurry phone photos, unrelated factory stock.

## Deliverables

- WebP/JPEG optimized images at 2400px wide for hero/gallery.
- Square crops for cards.
- Transparent PNG/SVG logo if available.
- Short alt-text notes for every product photo.
